# Unseen incident results

Produced by `POST /scan` against the unseen slice — no case list, no ground truth, no hints.
The endpoint sweeps every metric globally *and* every value of every dimension, folds echoes of
the same underlying event, and returns a full Evidence Bundle per finding.

| File | What it is |
|---|---|
| `diagnosis.txt` | The plain-language diagnosis, as generated |
| `query_results.csv` | The numbers behind it, straight from ClickHouse |
| `system_trace.log` | The Langfuse trace, proving the diagnosis was generated by the pipeline |

Every figure in the diagnosis is computed by SQL before the narrator sees it, and
`narrator/guardrail.py` rejects any number in the prose that is absent from the bundle — so the
diagnosis cannot contain a figure the queries did not produce.

Reproduce it:

```bash
curl -X POST https://clickathon.kangasys.com/api/scan \
  -H 'Content-Type: application/json' \
  -d '{"start":"<slice start>","end":"<slice end>"}'
```
