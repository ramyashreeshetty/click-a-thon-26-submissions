# Graded outputs — Atlys track

Everything the Atlys submission guidelines' "Unseen Data/Surprise Round folder" item
asks for, in one place:

- **`ddl/`** — generated DDL for all 5 known feature specs, plus the 6th (sealed,
  revealed at judging).
- **`insights/`** — the Analytics Agent's reports: the required 4-prompt standard
  probe set, the autonomous "insight report over the 8 existing tables" run, and
  bonus spec-tied insights beyond what's required.
- **`context/`** — the context layer's before/after changelog (context-freshness
  proof) plus a full snapshot.
- **`6th_spec/`** — the 6th-spec bundle: generated schema + insight summary (written
  for a product audience) + trace, as its own write-up.

Trace links for every run referenced here live one level up, in `../traces.md`.
