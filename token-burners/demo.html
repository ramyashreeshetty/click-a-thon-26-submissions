The Challenge

Not Every Open Session
Is Actually Watching

Users background the app, pause playback, or silently disconnect. Counting those overstates the audience. We needed to identify only truly active playback intervals.

📱

Foreground Gate

App must be in foreground. AppBackgrounded → 0, AppForegrounded → 1

▶️

Playing Gate

Video must be actively playing. Pause → 0, Play/Resume → 1

🛑

Ended Gate

Session must not have ended. VideoSessionEnd → 1 (absorbing state)

⏱️

Freshness Cap

Must have received an event within 90 seconds. Auto-closes dead sessions.

active(t) = fg=1 AND playing=1 AND ended=0 AND fresh(≤90s)
