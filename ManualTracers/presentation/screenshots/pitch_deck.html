The Problem

When revenue or fill rate drops, analysts spend hours slicing dashboards by app, device, OS, region, and advertiser.

The data was there from minute one. The bottleneck is the manual investigation.

Our goal: automate the "why" in seconds, not days.

How It Works

Core principle: ClickHouse computes. The LLM only narrates. The model never sees raw rows or does arithmetic.

The Investigation Ladder

Fixed steps. No model picks the next query.

  1. Reproduce: recompute the global series live (don't trust the alert)
  2. Decompose: which funnel stage moved? (requests × fill × render × eCPM)
  3. Scan: score all 62 dimension slices in one ARRAY JOIN query
  4. Holdout: recompute on the complement; kills bleed-through
  5. Cross-check: confirm fault level (e.g. OS, not device model)

Example: five dimensions lit up for Android 15. One survived holdout. Four were ruled out.

Unseen Incident

Built for data we have never seen:

  • No hardcoded dates, segments, or thresholds
  • Same registry, same ladder, new dataset → new diagnosis
  • Trace proves the system generated it. No trace, no credit.

Playbook: replay → compress clock → re-provision alerts → wait or curl trigger → capture report + Langfuse trace.

What We Deliberately Didn't Build

  • No per-metric agents: one registry-driven agent
  • No LLM-written SQL: fixed parameterised queries only
  • No pre-aggregated rollup: one definition, executed everywhere
  • No polished auth or PagerDuty: judges score the investigation loop

Every "no" trades scaffolding for analytical depth and traceability.

Judge Q&A

"How do you stop hallucinations?" Grounding check. One unmatched number → throw away LLM output → template from ledger.
"Why not let the LLM write SQL?" Can't trace intent, slower, can return plausible wrong numbers. Fixed ladder is verifiable.
"Why marginal tiles?" Global-only alerting missed iOS 18.1 entirely. One extra query per metric closes the blind spot.
"False positives?" We name them honestly, e.g. Android 15 recovery flagged at z=6.3 (baseline contamination). Fix designed, not yet built.
