# Submission evidence

Add evidence generated by the actual graded run here before submitting. Do not
commit credentials, raw customer data, or fabricated examples.

- `langfuse/` — public Langfuse share links (in a Markdown file) or exported
  trace/observation JSON for each required run.
- `clickstack/` — dashboard or trace-search captures used in the demo, plus a
  short Markdown note identifying the ClickHouse instance and time range.

The root README explains how these artifacts map to the working telemetry
pipeline.
